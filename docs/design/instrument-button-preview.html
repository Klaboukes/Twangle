Instrument and tuning · rough mock-up

One button or two?

The bar loses its Instrument item and keeps three real tabs. The line above the strings becomes a real button that looks like the More tools button beside it. Each option is shown twice: a short English name, and an 8-string guitar with a 40-character own tuning in Dutch. Buttons keep the same size whatever they say. A name that doesn't fit first shrinks a little, then ends in "…".

The dashed line is where the meter ends. Anything that makes the controls taller takes height from the meter.

Not shown: chromatic mode (no strings, so no button; tap "Strings" to get it back), and the Chords and Capo tools in Practice, which would get the same button and open the same panel there.
