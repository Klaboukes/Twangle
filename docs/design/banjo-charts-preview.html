Banjo chord charts and scales

What's being decided: how Chords and Scales draw the banjo's short 5th string, and when it rings. Each row has options A and B (row 1 a C too), the one I'd pick marked. Choose one per row with its Pick button; the page keeps your picks.

1. Where the chart draws the short string

The first three banjo chords, G, C and D7, in open G (g D G B D). The short string is the first one, on the thick side.

2. When the short string rings

Its g is a G chord note (the root) and a C chord note (the 5th), but not a D7 note. Drawn the way you picked in row 1 (my pick until you choose). ▶ strums the chart.

3. The Scales neck

G major on the whole neck, on its side as on a phone and upright as on a tablet held upright. The short string has no notes below the 5th fret either way; its open g sits where its own nut is.

4. Left-handed

Not a choice: rows 1 and 3 as you picked them (or my picks), mirrored with Phase 57's Left-handed switch.

5. What TalkBack says for the short string

Every string is named by its open note today ("D 3 string"). Frets on the short string are counted on the neck either way, as banjo tab does ("fret 7" for its a).

The shapes, checked note by note

G: every string open: g D G B D, all G chord notes. C: 4th string 2nd fret (finger 2), 2nd string 1st fret (finger 1), 1st string 2nd fret (finger 3): g E G C E; the lowest note is the E, not the C, as banjo players play it. D7: 3rd string 2nd fret (finger 2), 2nd string 1st fret (finger 1), 1st string 4th fret (finger 4): D A C F♯, the 4th string open as the root; the short string's g is not a D7 note.

Not shown: the other five styles, every language and 2× text, double C and double D (the same rules), and the Capo helper, which keeps its quiet line for the banjo until players ask.
