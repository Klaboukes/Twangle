Open mock-ups and preview pages (docs/design/…html) for the owner in Firefox: `Start-Process "C:\Program Files\Mozilla Firefox\firefox.exe" -ArgumentList "<full path to the html>"`. Don't use the built-in browser pane for them.

**Why:** owner, 2026-10-26: sounds wouldn't play in the built-in browser (the drone samples page); "do this for all mockups in the future".

**How to apply:** whenever a mock-up or sound preview is ready for the owner, open it in Firefox yourself and still give the file link. CLAUDE.md's Workflow section says the same (so the laptop follows it too).
